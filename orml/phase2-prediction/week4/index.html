Week 4: 机器学习工作流、Baseline 与线性模型 ​

核心目标 ​

学会建立一个可靠的 supervised learning（监督学习）流程，而不是只会调用 .fit()。

本周问题 ​

核心问题

我们要预测什么？用什么信息预测？如何知道预测是否可信？

知识地图 ​

必学内容 ​

1. ML 基础概念 ​

  • Feature（特征） 与 Target（目标）
  • Prediction（预测） 的本质
  • Regression（回归） 与 Classification（分类）

2. 数据切分 ​

  • train/validation/test split
  • chronological split（按时间切分）
  • 为什么不能随机切分时间数据

3. Baseline ​

  • 为什么必须先建立 Baseline
  • 回归 Baseline 的构建方法
  • 如何判断模型是否真正有用

4. 线性回归 ​

  • 模型公式与解释
  • 系数的方向和单位
  • 预测值的构成

5. 评价指标 ​

  • MAE、MSE、RMSE
  • 残差分析
  • 误差图解读

本周学习路线 ​

关键概念预览 ​

监督学习流程 ​

历史数据 → 训练模型 → 对新数据预测 → 评价效果

核心问题 ​

  1. 预测什么？ → Target
  2. 用什么预测？ → Features
  3. 如何训练？ → 算法选择
  4. 如何验证？ → 数据切分
  5. 如何评价？ → 指标选择

为什么 Baseline 如此重要？ ​

常见误区

很多初学者直接训练复杂模型，得到"看起来不错"的分数，但没有与 Baseline 比较。

问题：

  • 模型是否真正学到有用的信息？
  • 是否只是记住了训练数据？
  • 简单方法是否已经足够好？

Baseline 的作用 ​

  1. 参考基准： 模型必须比"什么都不做"更好
  2. 问题诊断： 如果连 Baseline 都打不过，说明有问题
  3. 效果评估： 多少改进来自模型，多少来自数据本身

本周产出 ​

Milestone 4：可靠预测基线 ​

任务： 建立并比较两个 Baseline 和一个线性回归模型

通过标准：

  • 明确预测时点
  • 正确切分数据
  • 报告 MAE 或 RMSE
  • 模型与 Baseline 比较
  • 给出至少一个残差图或错误案例分析

交付物：

  • 04_ml_workflow_linear.ipynb
  • 模型比较表

Research Thinking ​

Research Thinking

Why Baseline？没有 Baseline 的模型提升为什么缺乏解释力？

提示：考虑数据本身的可预测性、模型复杂度的必要性、过拟合风险。
