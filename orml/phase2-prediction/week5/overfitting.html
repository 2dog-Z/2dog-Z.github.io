过拟合与正则化 ​

Overfitting vs Underfitting ​

概念 ​

状态训练误差测试误差模型复杂度
Underfitting（欠拟合）高高太简单
Overfitting（过拟合）低高太复杂
Good Fit（合适拟合）低低适中

过拟合的表现 ​

症状 ​

  1. 训练集表现极好，测试集表现差
  2. 模型过于复杂（如树深度太大）
  3. 对小数据变化非常敏感

可视化理解 ​

python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
from sklearn.pipeline import Pipeline

np.random.seed(42)

# 数据
X = np.linspace(0, 10, 20)
y_true = 2 * X + 1
y = y_true + np.random.normal(0, 2, 20)

# 不同复杂度模型
degrees = [1, 3, 15]
fig, axes = plt.subplots(1, 3, figsize=(15, 5))

for idx, degree in enumerate(degrees):
    # 拟合多项式
    model = Pipeline([
        ('poly', PolynomialFeatures(degree=degree)),
        ('linear', LinearRegression())
    ])
    model.fit(X.reshape(-1, 1), y)

    # 预测
    X_test = np.linspace(0, 10, 100)
    y_pred = model.predict(X_test.reshape(-1, 1))

    # 可视化
    axes[idx].scatter(X, y, color='#2196F3', s=100, label='数据点', zorder=3)
    axes[idx].plot(X_test, y_true, '--', color='gray', label='真实关系', alpha=0.7)
    axes[idx].plot(X_test, y_pred, color='#F44336', linewidth=2, label=f'多项式 (度={degree})')

    axes[idx].set_xlabel('X')
    axes[idx].set_ylabel('y')
    axes[idx].legend()
    axes[idx].grid(True, alpha=0.3)

    # 标题
    if degree == 1:
        axes[idx].set_title('欠拟合\n模型太简单')
    elif degree == 15:
        axes[idx].set_title('过拟合\n模型太复杂')
    else:
        axes[idx].set_title('合适拟合\n复杂度适中')

plt.tight_layout()
plt.show()

1. 限制模型复杂度 ​

python
from sklearn.tree import DecisionTreeRegressor

# 限制复杂度的参数
tree = DecisionTreeRegressor(
    max_depth=5,              # 最大深度

    min_samples_leaf=5,       # 叶节点最小样本数
    max_leaf_nodes=20         # 最大叶节点数

python
from sklearn.ensemble import GradientBoostingRegressor
from sklearn.metrics import mean_absolute_error

# 梯度提升（需要 early stopping）
gb = GradientBoostingRegressor(
    n_estimators=500,
    validation_fraction=0.2,
    n_iter_no_change=10,  # 早停
    random_state=42

gb.fit(X_train, y_train)
