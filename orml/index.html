📚 科研主线叙事 ​

本课程以一个核心科研问题统领全部 10 周内容：

How can data help us make better decisions under uncertainty? 数据如何帮助我们在不确定性下做出更好的决策？

贯穿全课程的核心判断是：

Probability 是描述现实世界不确定性的语言；Prediction 创造信息，Decision 创造价值；Robustness 决定结论是否可信。

🎯 学习目标 ​

完成本规划后，你将能够：

  • ✅ 用 Python 完成数据清洗、可视化、基础统计分析与模拟
  • ✅ 正确区分训练集、验证集和测试集，并搭建无明显数据泄漏的机器学习流程
  • ✅ 使用 scikit-learn 训练和比较基础回归、分类模型
  • ✅ 把现实问题翻译为 Decision Variable（决策变量）、Objective Function（目标函数）和 Constraint（约束）
  • ✅ 使用 PuLP 或 OR-Tools 建立并求解基础 LP 和 MIP 模型
  • ✅ 完成一个"预测 + 优化"的端到端项目，并能向教授解释问题、假设、方法、实验和局限

📅 时间安排 ​

  • 总时长：10 周
  • 每周投入：建议 6-8 小时
  • 适合人群：零基础学习者，具备基础编程能力和高中数学知识

🛠️ 工具准备 ​

在开始学习之前，请确保安装以下工具：

  • Python 3.10+
  • Jupyter Notebook
  • VS Code（推荐）
