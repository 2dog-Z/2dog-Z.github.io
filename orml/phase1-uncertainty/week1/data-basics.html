数据基础 ​

核心概念 ​

Observation（观测） ​

定义： 一个独立的数据记录，通常对应表格中的一行。

生活例子：

  • 一行医院记录 = 一个病人的某次就诊
  • 一行销售记录 = 一笔交易
  • 一行共享单车记录 = 某站点某小时的需求

数学表达：

Observationi=(xi1,xi2,…,xip)\text{Observation}_i = (x_{i1}, x_{i2}, \ldots, x_{ip}) Observation​i​​=(x​i1​​,x​i2​​,…,x​ip​​)

其中 iii 表示第 iii 个观测，ppp 表示特征数量。

Feature（特征） ​

定义： 用于描述观测的属性，通常对应表格中的列。

类型：

类型说明例子
Numerical（数值型）连续或离散数值温度、需求量、库存
Categorical（类别型）有限个类别站点ID、天气类型
Binary（二元型）只有两个取值是否工作日、是否雨天
Temporal（时间型）时间相关日期、小时

Target（目标） ​

定义： 我们想要预测或解释的变量。

例子：

问题类型Target
需求预测demand（需求量）
分类问题is_high_demand（是否高需求）
优化问题cost（成本）

常见数据问题 ​

1. 缺失值 ​

原因：

  • 数据采集失败
  • 信息不适用
  • 系统错误

处理方法：

python
# 删除
df_clean = df.dropna()

# 填充均值
df['temperature'].fillna(df['temperature'].mean(), inplace=True)

# 填充中位数
df['demand'].fillna(df['demand'].median(), inplace=True)

# 前向填充（时间序列）
df['inventory'].fillna(method='ffill', inplace=True)

2. 异常值 ​

检测方法：

python
# 描述统计
print(df['demand'].describe())

# 箱线图
import matplotlib.pyplot as plt
plt.boxplot(df['demand'])
plt.show()

# Z-score
from scipy import stats
z_scores = stats.zscore(df['demand'])
outliers = df[abs(z_scores) > 3]

处理方法：

python
# 删除异常值
df_clean = df[abs(z_scores) <= 3]

# 截断
upper_limit = df['demand'].quantile(0.99)
df['demand_capped'] = df['demand'].clip(upper=upper_limit)

3. 单位不一致 ​

例子： 混淆华氏度和摄氏度

python
# 检查范围
print(df['temperature'].describe())

# 如果温度范围在 50-100，可能是华氏度
# 转换为摄氏度
if df['temperature'].max() > 40:
    df['temperature_c'] = (df['temperature'] - 32) * 5/9

代码示例 ​

python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# 读取数据
df = pd.read_csv('bike_demand.csv')

# 数据概览
print("=== 数据概览 ===")
print(f"维度: {df.shape}")
print(f"\n列名:\n{df.columns.tolist()}")
print(f"\n数据类型:\n{df.dtypes}")

# 检查缺失值
print("\n=== 缺失值 ===")
print(df.isnull().sum())

# 统计摘要
print("\n=== 统计摘要 ===")
print(df.describe())

# 分布可视化
fig, axes = plt.subplots(2, 2, figsize=(12, 8))

# 需求分布
axes[0, 0].hist(df['demand'], bins=30, edgecolor='black')
axes[0, 0].set_title('Demand Distribution')

# 每小时需求
df.groupby('hour')['demand'].mean().plot(kind='bar', ax=axes[0, 1])
axes[0, 1].set_title('Average Demand by Hour')

# 温度 vs 需求
axes[1, 0].scatter(df['temperature'], df['demand'], alpha=0.3)
axes[1, 0].set_xlabel('Temperature')
axes[1, 0].set_ylabel('Demand')
axes[1, 0].set_title('Temperature vs Demand')

# 工作日 vs 周末
df.groupby('is_weekday')['demand'].mean().plot(kind='bar', ax=axes[1, 1])
axes[1, 1].set_title('Weekday vs Weekend Demand')
axes[1, 1].set_xticklabels(['Weekend', 'Weekday'], rotation=0)

plt.tight_layout()
plt.show()
