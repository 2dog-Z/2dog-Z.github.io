NumPy & Pandas ​

概述 ​

NumPy 和 Pandas 是 Python 数据科学生态的核心工具：

  • NumPy：高效的多维数组和数值计算
  • Pandas：表格数据处理和分析

NumPy 基础 ​

为什么需要 NumPy？ ​

Python 原生列表处理数值计算效率较低。NumPy 提供了：

  1. ndarray：高效的多维数组
  2. 向量化操作：无需循环即可批量计算
  3. 广播机制：不同形状数组间的运算

创建数组 ​

python
import numpy as np

# 从列表创建
arr = np.array([1, 2, 3, 4, 5])

# 创建特殊数组
zeros = np.zeros(5)        # [0. 0. 0. 0. 0.]
ones = np.ones(5)          # [1. 1. 1. 1. 1.]
arange = np.arange(0, 10, 2)  # [0 2 4 6 8]

# 创建二维数组
matrix = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
print(matrix.shape)  # (2, 3) — 2行3列

索引与切片 ​

python
arr = np.array([10, 20, 30, 40, 50])

# 单元素索引
print(arr[0])    # 10
print(arr[-1])   # 50

# 切片
print(arr[1:4])  # [20 30 40]

# 二维数组索引
matrix = np.array([[1, 2, 3], [4, 5, 6]])
print(matrix[0, 1])     # 2 — 第0行第1列
print(matrix[:, 0])     # [1 4] — 所有行的第0列
print(matrix[1, :])     # [4 5 6] — 第1行所有列

向量化操作 ​

python
# 无需循环！
arr = np.array([1, 2, 3, 4, 5])

# 所有元素同时运算
print(arr * 2)      # [ 2  4  6  8 10]
print(arr + 10)     # [11 12 13 14 15]
print(arr ** 2)     # [ 1  4  9 16 25]

# 统计函数
print(arr.mean())   # 3.0
print(arr.sum())    # 15
print(arr.std())    # 1.414...

向量化的意义

向量化操作比 Python 循环快 10-100 倍，这是 NumPy 的核心价值。

Pandas 基础 ​

DataFrame 是什么？ ​

DataFrame（数据表） 是一个二维表格结构：

  • 每行代表一条 observation（观测）
  • 每列代表一个 feature（特征） 或 target（目标）
python
import pandas as pd

# 创建 DataFrame
df = pd.DataFrame({
    'station_id': ['A001', 'A002', 'A003'],
    'hour': [8, 12, 18],
    'demand': [45, 120, 85],
    'is_weekend': [False, False, False]
})

print(df)

输出：

  station_id  hour  demand  is_weekend
0       A001     8      45       False
1       A002    12     120       False
2       A003    18      85       False

读取数据 ​

python
# 读取 CSV
df = pd.read_csv('bike_demand.csv')

# 查看基本信息
print(df.head())        # 前5行
print(df.shape)         # (行数, 列数)
print(df.columns)       # 列名
print(df.dtypes)        # 每列数据类型
print(df.info())        # 综合信息

选择数据 ​

python
# 选择单列
df['demand']

# 选择多列
df[['station_id', 'demand']]

# 按行号选择
df.iloc[0]          # 第0行
df.iloc[0:5]        # 前5行

# 按条件过滤
df[df['demand'] > 50]               # 需求大于50的行
df[df['is_weekend'] == True]        # 周末数据
df[(df['hour'] >= 8) & (df['hour'] <= 18)]  # 8-18点

分组与聚合 ​

python
# 按站点分组，计算平均需求
df.groupby('station_id')['demand'].mean()

# 按小时分组，计算总需求和记录数
df.groupby('hour').agg({
    'demand': ['sum', 'mean', 'count']
})

# 多层分组
df.groupby(['station_id', 'is_weekend'])['demand'].mean()

处理缺失值 ​

python
# 检查缺失
df.isnull().sum()

# 删除含缺失值的行
df.dropna()

# 填充缺失值
df['demand'].fillna(0)              # 用0填充
df['demand'].fillna(df['demand'].mean())  # 用均值填充

# 前向填充（用上一行值填充）
df.fillna(method='ffill')

实例：共享单车数据处理 ​

python
import pandas as pd

# 读取数据
df = pd.read_csv('sample_bike_data.csv')

# 1. 基础检查
print("数据形状:", df.shape)
print("\n列名:", df.columns.tolist())
print("\n数据类型:\n", df.dtypes)

# 2. 检查缺失值
print("\n缺失值统计:\n", df.isnull().sum())

# 3. 描述性统计
print("\n数值列统计:\n", df.describe())

# 4. 分组分析
hourly_demand = df.groupby('hour')['demand'].mean()
print("\n每小时平均需求:\n", hourly_demand)

# 5. 条件筛选
high_demand = df[df['demand'] > df['demand'].quantile(0.9)]
print(f"\n高需求记录数: {len(high_demand)}")

# 6. 新建派生列
df['demand_per_bike'] = df['demand'] / df['available_bikes']
df['is_rush_hour'] = df['hour'].isin([8, 9, 17, 18, 19])
