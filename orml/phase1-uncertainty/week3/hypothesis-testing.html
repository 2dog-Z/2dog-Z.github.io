假设检验 ​

什么是 Hypothesis Testing（假设检验）？ ​

Hypothesis Testing（假设检验） 是一种统计方法，用于根据样本数据判断关于总体的某个假设是否合理。

核心思想 ​

直觉理解

假设检验就像"无罪推定"原则：

  1. 先假设"没有差异"（原假设）
  2. 看样本证据是否足够强
  3. 如果证据"不太可能"在原假设下出现，则拒绝原假设

假设检验的基本要素 ​

Null Hypothesis（原假设）H0H_0H​0​​ ​

  • 表示"没有差异"或"没有效果"的假设
  • 通常是我们想要挑战的假设
  • 例：H0:μ=5000H_0: \mu = 5000H​0​​:μ=5000（平均需求等于 5000）

Alternative Hypothesis（备择假设）H1H_1H​1​​ 或 HaH_aH​a​​ ​

  • 表示"有差异"或"有效果"的假设
  • 例：H1:μ≠5000H_1: \mu \neq 5000H​1​​:μ≠5000（平均需求不等于 5000）

检验类型 ​

类型备择假设适用场景
双侧检验H1:μ≠μ0H_1: \mu \neq \mu_0H​1​​:μ≠μ​0​​检验是否有差异
左侧检验H1:μ<μ0H_1: \mu < \mu_0H​1​​:μ<μ​0​​检验是否更小
右侧检验H1:μ>μ0H_1: \mu > \mu_0H​1​​:μ>μ​0​​检验是否更大

p-value 的含义 ​

定义 ​

p-value（p 值） 是在原假设为真的前提下，观察到当前或更极端结果的概率。

判断标准 ​

  • 显著性水平 α\alphaα： 通常设为 0.05 或 0.01
  • 决策规则：
    • 若 p<αp < \alphap<α，拒绝 H0H_0H​0​​
    • 若 p≥αp \geq \alphap≥α，不拒绝 H0H_0H​0​​

p-value 的正确解释 ​

常见误区

错误解释：

❌ "p = 0.03 意味着原假设有 3% 的概率为真" ❌ "p = 0.03 意味着结果有 97% 的概率是正确的"

正确解释：

✅ "如果原假设为真，观察到当前或更极端结果的概率是 3%" ✅ "在原假设下，这样的数据出现概率很低（3%），因此我们怀疑原假设"

假设检验的步骤 ​

标准流程 ​

  1. 陈述假设： 明确 H0H_0H​0​​ 和 H1H_1H​1​​
  2. 选择显著性水平： 通常 α=0.05\alpha = 0.05α=0.05
  3. 计算检验统计量： 如 t 统计量
  4. 计算 p-value
  5. 做出决策： 比较 p-value 与 α\alphaα
  6. 解释结果： 用通俗语言说明

示例：单样本 t 检验 ​

问题设置 ​

某共享单车站点声称平均日需求为 200 人次。收集了 25 天的数据，样本均值为 185，标准差为 30。

问题： 样本数据是否足以反驳声称的平均需求？

手算步骤 ​

步骤 1：陈述假设

H0:μ=200vsH1:μ≠200H_0: \mu = 200 \quad \text{vs} \quad H_1: \mu \neq 200 H​0​​:μ=200vsH​1​​:μ≠200

步骤 2：选择显著性水平

α=0.05\alpha = 0.05 α=0.05

步骤 3：计算 t 统计量

t=x¯−μ0s/n=185−20030/25=−156=−2.5t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}} = \frac{185 - 200}{30 / \sqrt{25}} = \frac{-15}{6} = -2.5 t=​s/√​n​​​​​​x​¯​​−μ​0​​​​=​30/√​25​​​​​185−200​​=​6​​−15​​=−2.5

步骤 4：计算 p-value

自由度 df=n−1=24df = n - 1 = 24df=n−1=24

代码实现 ​

python
import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

# 已知数据
sample_mean = 185
sample_std = 30
n = 25
mu_0 = 200  # 原假设下的均值

# 计算 t 统计量
t_statistic = (sample_mean - mu_0) / (sample_std / np.sqrt(n))

# 计算 p-value（双侧检验）
p_value = 2 * stats.t.sf(abs(t_statistic), df=n-1)

print(f"t 统计量: {t_statistic:.3f}")
print(f"p-value: {p_value:.4f}")

# 决策
alpha = 0.05
if p_value < alpha:
    print(f"结论: p-value ({p_value:.4f}) < α ({alpha})，拒绝 H₀")
    print("样本数据支持平均需求不等于 200 人次的结论")
else:
    print(f"结论: p-value ({p_value:.4f}) ≥ α ({alpha})，不拒绝 H₀")

# 可视化
t_dist = stats.t(df=n-1)
x = np.linspace(-4, 4, 1000)
y = t_dist.pdf(x)

plt.figure(figsize=(10, 6))
plt.plot(x, y, color='#2196F3', linewidth=2, label='t 分布 (df=24)')

# 拒绝域
x_reject_left = x[x < -stats.t.ppf(0.975, df=n-1)]
x_reject_right = x[x > stats.t.ppf(0.975, df=n-1)]

plt.fill_between(x_reject_left, t_dist.pdf(x_reject_left), color='red', alpha=0.3, label='拒绝域')
plt.fill_between(x_reject_right, t_dist.pdf(x_reject_right), color='red', alpha=0.3)

# 观察到的 t 值
plt.axvline(t_statistic, color='green', linestyle='--', linewidth=2, label=f'观察到的 t = {t_statistic:.2f}')

plt.xlabel('t 值')
plt.ylabel('概率密度')
plt.title('单样本 t 检验')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

双样本 t 检验 ​

问题 ​

工作日和周末的平均需求是否有显著差异？

python
import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

np.random.seed(42)

# 生成数据
weekday_demand = np.random.normal(220, 40, 50)
weekend_demand = np.random.normal(180, 35, 50)

# 描述统计
print("工作日需求:")
print(f"  均值: {weekday_demand.mean():.2f}")
print(f"  标准差: {weekday_demand.std():.2f}")
print("\n周末需求:")
print(f"  均值: {weekend_demand.mean():.2f}")
print(f"  标准差: {weekend_demand.std():.2f}")

# 双样本 t 检验
t_stat, p_value = stats.ttest_ind(weekday_demand, weekend_demand)

print(f"\n双样本 t 检验:")
print(f"  t 统计量: {t_stat:.3f}")
print(f"  p-value: {p_value:.4f}")

if p_value < 0.05:
    print("  结论: 工作日和周末需求有显著差异")
else:
    print("  结论: 没有足够证据表明有显著差异")

# 可视化
plt.figure(figsize=(10, 6))
plt.hist(weekday_demand, bins=20, alpha=0.6, color='#4CAF50', label='工作日', edgecolor='white')
plt.hist(weekend_demand, bins=20, alpha=0.6, color='#FF9800', label='周末', edgecolor='white')
plt.axvline(weekday_demand.mean(), color='#4CAF50', linestyle='--', linewidth=2)
plt.axvline(weekend_demand.mean(), color='#FF9800', linestyle='--', linewidth=2)
plt.xlabel('日需求量')
plt.ylabel('频数')
plt.title('工作日 vs 周末需求分布')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

统计显著 ≠ 实际重要 ​

关键警告 ​

重要区别

Statistically Significant（统计显著） ≠ Practically Important（实际重要）

  • 统计显著只说明"不太可能是随机波动"
  • 不说明"差异足够大，值得关心"
  • 大样本下，很小的差异也能"统计显著"

示例 ​

python
import numpy as np
from scipy import stats

np.random.seed(42)

# 场景 1：大样本，小差异
large_sample_A = np.random.normal(100, 15, 10000)
large_sample_B = np.random.normal(101, 15, 10000)

t_stat1, p_value1 = stats.ttest_ind(large_sample_A, large_sample_B)

print("场景 1：大样本 (n=10000)")
print(f"  样本 A 均值: {large_sample_A.mean():.2f}")
print(f"  样本 B 均值: {large_sample_B.mean():.2f}")
print(f"  差异: {large_sample_B.mean() - large_sample_A.mean():.2f}")
print(f"  p-value: {p_value1:.6f}")
print(f"  统计显著? {'是' if p_value1 < 0.05 else '否'}")
print(f"  实际重要? 差异只有 1，可能不重要")

print("\n" + "="*50 + "\n")

# 场景 2：小样本，大差异
small_sample_A = np.random.normal(100, 15, 20)
small_sample_B = np.random.normal(115, 15, 20)

t_stat2, p_value2 = stats.ttest_ind(small_sample_A, small_sample_B)

print("场景 2：小样本 (n=20)")
print(f"  样本 A 均值: {small_sample_A.mean():.2f}")
print(f"  样本 B 均值: {small_sample_B.mean():.2f}")
print(f"  差异: {small_sample_B.mean() - small_sample_A.mean():.2f}")
print(f"  p-value: {p_value2:.4f}")
print(f"  统计显著? {'是' if p_value2 < 0.05 else '否'}")
print(f"  实际重要? 差异约 15，可能重要")

检验的功效（Power） ​

定义 ​

Power（功效） = 正确拒绝错误原假设的概率

Power=1−β\text{Power} = 1 - \beta Power=1−β

其中 β\betaβ 是 Type II Error（第二类错误）的概率。

影响因素 ​

  • 样本量： 样本越大，功效越高
  • 效应大小： 差异越大，功效越高
  • 显著性水平： α\alphaα 越大，功效越高
  • 总体方差： 方差越小，功效越高

假设检验与机器学习 ​

类比关系 ​

统计检验机器学习
原假设 H0H_0H​0​​模型无效假设
备择假设 H1H_1H​1​​模型有效假设
p-value看起来好但实际可能是运气
统计显著在测试集上表现好
过拟合数据泄漏导致虚假显著

实际应用 ​

python
import numpy as np
from scipy import stats

# 比较 ML 模型和 baseline
baseline_errors = np.array([45, 52, 48, 55, 49, 51, 47, 53, 50, 46])
ml_model_errors = np.array([40, 48, 45, 50, 44, 47, 43, 49, 46, 42])

# 检验 ML 模型是否显著优于 baseline
# 使用单侧检验（我们只关心 ML 是否更好）
t_stat, p_value = stats.ttest_rel(baseline_errors, ml_model_errors)

print("模型比较:")
print(f"  Baseline 平均误差: {baseline_errors.mean():.2f}")
print(f"  ML 模型平均误差: {ml_model_errors.mean():.2f}")
print(f"  差异: {baseline_errors.mean() - ml_model_errors.mean():.2f}")
print(f"  p-value (双侧): {p_value:.4f}")
print(f"  p-value (单侧): {p_value/2:.4f}")

if p_value/2 < 0.05:
    print("  结论: ML 模型显著优于 baseline")
else:
    print("  结论: 没有足够证据表明 ML 模型更好")
