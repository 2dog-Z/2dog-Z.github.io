概率基础 ​

什么是概率？ ​

Probability（概率） 是衡量事件发生可能性的数值，范围在 0 到 1 之间。

  • 0：不可能发生
  • 1：必然发生
  • 0.5：发生和不发生的可能性相等

Event（事件） ​

Event（事件） 是我们关心的结果集合。

例子：共享单车租赁 ​

假设我们观察一个站点在某个小时内是否有人来租车：

  • 事件 A：至少有一人来租车
  • 事件 B：需求超过 50 次
python
import random

# 模拟 100 个小时的观察
results = []
for _ in range(100):
    demand = random.randint(0, 80)  # 模拟需求数
    has_customer = demand > 0        # 事件 A
    high_demand = demand > 50        # 事件 B
    results.append((has_customer, high_demand))

# 计算概率
prob_A = sum(r[0] for r in results) / 100
prob_B = sum(r[1] for r in results) / 100

print(f"P(至少有1人) ≈ {prob_A:.2f}")
print(f"P(需求>50) ≈ {prob_B:.2f}")

概率的直觉 ​

频率解释 ​

在大量重复实验中，事件发生的频率趋近于概率。

python
import numpy as np

# 抛硬币模拟
n_flips = [10, 100, 1000, 10000]

for n in n_flips:
    flips = np.random.choice(['H', 'T'], size=n)
    prob_heads = (flips == 'H').mean()
    print(f"抛 {n:5d} 次，正面概率 ≈ {prob_heads:.3f}")

输出：

抛    10 次，正面概率 ≈ 0.500
抛   100 次，正面概率 ≈ 0.480
抛  1000 次，正面概率 ≈ 0.502
抛 10000 次，正面概率 ≈ 0.498

规律： 样本量越大，频率越接近真实概率。

Conditional Probability（条件概率） ​

定义 ​

条件概率 是在已知部分信息时，事件发生的概率。

P(A∣B)=P(A∩B)P(B)P(A|B) = \frac{P(A \cap B)}{P(B)} P(A∣B)=​P(B)​​P(A∩B)​​

读作：在 B 已经发生的条件下，A 发生的概率。

生活例子 ​

共享单车站点：

  • 事件 A：需求超过 50 次
  • 事件 B：是工作日
python
# 模拟数据
n_hours = 1000
data = []
for _ in range(n_hours):
    is_weekday = random.choice([True, False])
    if is_weekday:
        demand = random.randint(10, 80)  # 工作日需求较高
    else:
        demand = random.randint(5, 50)   # 周末需求较低
    data.append((is_weekday, demand))

# 计算概率
total = len(data)
weekday_data = [d for d in data if d[0]]
weekday_high = [d for d in weekday_data if d[1] > 50]

P_B = len(weekday_data) / total                    # P(工作日)
P_A_and_B = len(weekday_high) / total              # P(工作日 且 高需求)
P_A_given_B = P_A_and_B / P_B                      # P(高需求|工作日)

print(f"P(工作日) = {P_B:.2f}")
print(f"P(高需求|工作日) = {P_A_given_B:.2f}")

# 周末条件概率
weekend_data = [d for d in data if not d[0]]
weekend_high = [d for d in weekend_data if d[1] > 50]
P_A_given_not_B = len(weekend_high) / len(weekend_data)
print(f"P(高需求|周末) = {P_A_given_not_B:.2f}")

Bayes' Theorem（贝叶斯定理） ​

直觉理解 ​

贝叶斯定理告诉我们：如何根据新信息更新概率。

P(A∣B)=P(B∣A)⋅P(A)P(B)P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)} P(A∣B)=​P(B)​​P(B∣A)⋅P(A)​​

例子：判断是否是工作日 ​

假设你只观察到"现在需求很高"，想推断"今天是不是工作日"。

python
# 已知信息
P_weekday = 5/7                    # P(工作日) = 5/7
P_high_given_weekday = 0.35        # P(高需求|工作日)
P_high_given_weekend = 0.10        # P(高需求|周末)

# 计算 P(高需求)
P_high = P_high_given_weekday * P_weekday + P_high_given_weekend * (1 - P_weekday)
print(f"P(高需求) = {P_high:.2f}")

# 贝叶斯：P(工作日|高需求)
P_weekday_given_high = (P_high_given_weekday * P_weekday) / P_high
print(f"P(工作日|高需求) = {P_weekday_given_high:.2f}")

结论： 如果看到高需求，有大约 93% 的概率是工作日。

独立事件 ​

两个事件 独立（Independent） 如果：

P(A∩B)=P(A)⋅P(B)P(A \cap B) = P(A) \cdot P(B) P(A∩B)=P(A)⋅P(B)

检验独立性 ​

python
import numpy as np

# 模拟数据
np.random.seed(42)
n = 1000
is_rain = np.random.choice([0, 1], size=n, p=[0.8, 0.2])  # 20% 下雨
demand = np.random.randint(20, 80, size=n)

# 检验：下雨和高需求是否独立？
P_rain = is_rain.mean()
P_high = (demand > 50).mean()

# 联合概率
joint = ((is_rain == 1) & (demand > 50)).mean()

print(f"P(下雨) = {P_rain:.3f}")
print(f"P(高需求) = {P_high:.3f}")
print(f"P(下雨) × P(高需求) = {P_rain * P_high:.3f}")
print(f"P(下雨 且 高需求) = {joint:.3f}")

if abs(joint - P_rain * P_high) < 0.05:
    print("→ 两个事件近似独立")
else:
    print("→ 两个事件不独立")

思考问题
