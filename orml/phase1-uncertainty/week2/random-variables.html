随机变量 ​

什么是 Random Variable（随机变量）？ ​

Random Variable（随机变量） 是一个将随机结果映射到数值的函数。

  • 它不是一个"变量"，而是一个"规则"
  • 这个规则把每个可能的结果变成一个数字

例子：共享单车需求 ​

python
import random

# 定义一个随机变量 X = "某站点某小时的需求量"
# X 的可能取值：0, 1, 2, 3, ... (非负整数)

def simulate_demand():
    """模拟需求量 X"""
    return random.randint(0, 100)

# 观察多次
observations = [simulate_demand() for _ in range(10)]
print(f"10 次观察: {observations}")

离散 vs 连续 ​

离散随机变量 ​

取值是可数的（可以一一列举）

  • 需求量：0, 1, 2, 3, ...
  • 到达人数：0, 1, 2, 3, ...
  • 故障次数：0, 1, 2, ...

连续随机变量 ​

取值是不可数的（在某区间内连续）

  • 温度：15.2°C, 23.7°C, ...
  • 等待时间：3.5 分钟, 12.8 分钟, ...
  • 行驶距离：1.23 km, 5.67 km, ...

Expectation（期望） ​

定义 ​

Expectation（期望） 是随机变量在大量重复实验中的平均值。

E[X]=∑ixi⋅P(X=xi)E[X] = \sum_{i} x_i \cdot P(X = x_i) E[X]=​i​∑​​x​i​​⋅P(X=x​i​​)

或对于连续变量：

E[X]=∫x⋅f(x)dxE[X] = \int x \cdot f(x) \, dx E[X]=∫x⋅f(x)dx

计算例子 ​

python
import numpy as np

# 需求量的概率分布（简化模型）
# P(X=0)=0.05, P(X=20)=0.15, P(X=40)=0.30, P(X=60)=0.35, P(X=80)=0.15
values = np.array([0, 20, 40, 60, 80])
probs = np.array([0.05, 0.15, 0.30, 0.35, 0.15])

# 计算期望
expected_value = np.sum(values * probs)
print(f"期望需求 E[X] = {expected_value:.1f}")

# 验证：模拟
np.random.seed(42)
simulated = np.random.choice(values, size=10000, p=probs)
print(f"模拟平均需求 ≈ {simulated.mean():.1f}")

性质 ​

  1. 线性性：E[aX+b]=aE[X]+bE[aX + b] = aE[X] + bE[aX+b]=aE[X]+b
  2. 加法性：E[X+Y]=E[X]+E[Y]E[X + Y] = E[X] + E[Y]E[X+Y]=E[X]+E[Y]（无论 X, Y 是否独立）
  3. 乘法性：E[XY]=E[X]E[Y]E[XY] = E[X]E[Y]E[XY]=E[X]E[Y]（仅当 X, Y 独立）

Variance（方差） ​

定义 ​

Variance（方差） 衡量随机变量围绕期望的波动程度。

Var(X)=E[(X−E[X])2]=E[X2]−(E[X])2\text{Var}(X) = E[(X - E[X])^2] = E[X^2] - (E[X])^2 Var(X)=E[(X−E[X])​2​​]=E[X​2​​]−(E[X])​2​​

计算例子 ​

python
# 使用之前的数据
values = np.array([0, 20, 40, 60, 80])
probs = np.array([0.05, 0.15, 0.30, 0.35, 0.15])

# 计算方差
E_X = np.sum(values * probs)
E_X2 = np.sum(values**2 * probs)
variance = E_X2 - E_X**2
std_dev = np.sqrt(variance)

print(f"期望 E[X] = {E_X:.1f}")
print(f"方差 Var(X) = {variance:.1f}")
print(f"标准差 SD(X) = {std_dev:.1f}")

# 解读
print(f"\n解读：需求大约在 {E_X - std_dev:.1f} 到 {E_X + std_dev:.1f} 之间波动")

Covariance（协方差） ​

定义 ​

Covariance（协方差） 衡量两个随机变量是否"同向变化"。

Cov(X,Y)=E[(X−E[X])(Y−E[Y])]\text{Cov}(X, Y) = E[(X - E[X])(Y - E[Y])] Cov(X,Y)=E[(X−E[X])(Y−E[Y])]

  • Cov > 0：正相关（X 大时 Y 倾向于大）
  • Cov < 0：负相关（X 大时 Y 倾向于小）
  • Cov ≈ 0：无相关

例子：需求与温度 ​

python
import numpy as np

np.random.seed(42)

# 模拟温度和需求（正相关）
temperature = np.random.uniform(10, 35, 1000)
demand = 20 + 1.5 * temperature + np.random.normal(0, 10, 1000)

# 计算协方差
cov_matrix = np.cov(temperature, demand)
cov = cov_matrix[0, 1]

print(f"协方差 Cov(T, D) = {cov:.2f}")

# 相关系数（消除单位影响）
corr = np.corrcoef(temperature, demand)[0, 1]
print(f"相关系数 Corr(T, D) = {corr:.2f}")

⚠️ 注意 ​

  • 协方差的大小受单位影响
  • 相关系数在 -1 到 1 之间，更便于比较

Python 实现 ​

python
import numpy as np

# 模拟随机变量
np.random.seed(42)
X = np.random.randint(0, 100, 1000)  # 需求
Y = X + np.random.normal(0, 20, 1000)  # 可用车辆（与需求相关）

# 计算统计量
print(f"E[X] = {X.mean():.2f}")
print(f"Var(X) = {X.var():.2f}")
print(f"SD(X) = {X.std():.2f}")
print(f"Cov(X, Y) = {np.cov(X, Y)[0, 1]:.2f}")
print(f"Corr(X, Y) = {np.corrcoef(X, Y)[0, 1]:.2f}")

Research Thinking ​

思考问题

  1. 期望不等于每次都会出现的值：即使平均需求是 50，你几乎不可能看到恰好 50 的需求。这说明什么？

  2. 协方差受单位影响：如果把需求从"人次"改成"千人次"，协方差会怎样变化？相关系数呢？

  3. 方差与决策：两个站点有相同的平均需求，但方差不同。你会更愿意在哪个站点投资？为什么？
