Phase 1: Understanding Uncertainty ​

数据如何产生，观察值为什么波动，我们能知道多少？

阶段目标 ​

从数据生成过程出发，理解观察、波动、抽样与估计，为后续预测建立可信基础。

科研主线 ​

贯穿本阶段的三个核心问题：

  1. 数据是什么？ — 一行数据代表什么现实过程？特征和目标的关系是什么？
  2. 波动从哪里来？ — 为什么观察值会变化？随机性如何描述？
  3. 我们能知道多少？ — 从有限样本推测总体时，结论有多不确定？

Week 1: Python 数据工具与"数据是什么" ​

核心目标 ​

建立后续所有内容所需的最小工具能力，并理解 observation（观测）、feature（特征）、target（目标）和 unit（单位）。

必学内容 ​

  • Jupyter Notebook 的基本使用
  • NumPy array（数组）：形状、索引、向量化计算
  • Pandas DataFrame（数据表）：读取、选择、过滤、分组、缺失值
  • Matplotlib：折线图、柱状图、散点图、直方图
  • 数据类型与单位
  • tidy data（整洁数据）的基本概念
  • reproducibility（可复现性）：固定 random seed（随机种子）
  • GitHub repository 的最小结构

讲解情景 ​

使用一个"小型共享单车站点数据集"：每一行表示某站点某小时的需求、天气、是否工作日和当前库存。

重点解释：

  • 一行是什么
  • 一列是什么
  • 哪些列是输入
  • 哪一列是预测目标
  • 为什么不能只看平均值
  • 缺失值可能意味着什么

本周产出 ​

一个可运行 Notebook：01_data_basics.ipynb

Week 2: 概率、随机变量与模拟 ​

核心目标 ​

理解随机性不是"完全不可知"，而是可以用概率分布和模拟描述。

必学内容 ​

  • Event（事件）与 Probability（概率）
  • Conditional Probability（条件概率）
  • Bayes' Theorem（贝叶斯定理）的直觉
  • Random Variable（随机变量）
  • Expectation（期望）、Variance（方差）、Covariance（协方差）
  • Bernoulli、Binomial、Poisson、Gaussian Distribution
  • Law of Large Numbers（大数定律）的直觉
  • Monte Carlo Simulation（蒙特卡洛模拟）

本周产出 ​

一个可交互 Notebook：02_probability_simulation.ipynb，包含至少三张图。

👉 进入 Week 2 详细内容

Week 3: 抽样、估计与统计推断 ​

核心目标 ​

理解"从有限数据推测总体"时为什么会有不确定性，并建立与机器学习误差的连接。

必学内容 ​

  • Population（总体）与 Sample（样本）
  • Sampling Distribution（抽样分布）的直觉
  • Bias（偏差）与 Variance（方差）
  • Maximum Likelihood Estimation（最大似然估计）
  • Confidence Interval（置信区间）的正确含义
  • Hypothesis Testing（假设检验）的基本含义
  • p-value 的最低限度解释
  • bootstrap（自助法）的直觉与 Python 实现

本周产出 ​

03_inference_and_bootstrap.ipynb 与一页研究摘要。

核心判断 ​

Probability 是描述现实世界不确定性的语言。

理解数据生成过程、抽样波动和估计不确定性，是建立可信预测和决策的基础。
