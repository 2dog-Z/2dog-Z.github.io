工具安装指南 ​

在开始学习之前，请确保安装并配置以下工具。

一、Python 环境 ​

1.1 安装 Python ​

推荐版本：Python 3.10 或更高

macOS ​

bash
# 使用 Homebrew 安装
brew install python@3.10

# 或从官网下载安装包
# https://www.python.org/downloads/

Windows ​

  1. 访问 Python 官网
  2. 下载 Python 3.10+ 安装包
  3. 安装时勾选 "Add Python to PATH"

验证安装 ​

bash
python --version
# 或
python3 --version

1.2 创建虚拟环境（推荐） ​

bash
# 创建虚拟环境
python -m venv or_ml_env

# 激活虚拟环境
# macOS/Linux
source or_ml_env/bin/activate

# Windows
or_ml_env\Scripts\activate

二、Jupyter Notebook ​

2.1 安装 Jupyter ​

bash
pip install jupyter

2.2 启动 Jupyter Notebook ​

bash
jupyter notebook

浏览器会自动打开 http://localhost:8888

2.3 基本使用 ​

  • 新建 Notebook：点击右上角 "New" → "Python 3"
  • 运行单元格：Shift + Enter
  • 切换单元格类型：快捷键 M（Markdown）、Y（Code）

三、核心库安装 ​

创建 requirements.txt 文件：

text
# 数值计算
numpy>=1.24.0

# 数据处理
pandas>=2.0.0

# 可视化
matplotlib>=3.7.0
seaborn>=0.12.0

# 机器学习
scikit-learn>=1.3.0

# 运筹优化（二选一）
pulp>=2.7.0
# 或
# ortools>=9.6.0

# 工具
jupyter>=1.0.0
tqdm>=4.65.0

安装所有依赖：

bash
pip install -r requirements.txt

四、开发环境 ​

4.1 VS Code（推荐） ​

安装 ​

访问 VS Code 官网 下载安装

推荐扩展 ​

扩展名称用途
PythonPython 语言支持
JupyterNotebook 支持
Pylance智能提示
GitLensGit 增强
Markdown All in OneMarkdown 预览
Code Spell Checker拼写检查

4.2 配置 Python 解释器 ​

  1. 打开 VS Code
  2. 按 Cmd + Shift + P（Mac）或 Ctrl + Shift + P（Windows）
  3. 输入 "Python: Select Interpreter"
  4. 选择你的虚拟环境中的 Python

五、Git 和 GitHub ​

5.1 安装 Git ​

macOS ​

bash
brew install git

Windows ​

下载 Git for Windows

5.2 配置 Git ​

bash
# 设置用户名和邮箱
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"

# 查看配置
git config --list

5.3 创建 GitHub 账户 ​

  1. 访问 GitHub
  2. 注册账户
  3. 配置 SSH 密钥（推荐）
bash
# 生成 SSH 密钥
ssh-keygen -t ed25519 -C "你的邮箱"

# 查看公钥
cat ~/.ssh/id_ed25519.pub

# 将公钥添加到 GitHub Settings → SSH and GPG keys

5.4 创建项目仓库 ​

bash
# 初始化仓库
git init

# 添加文件
git add .

# 提交
git commit -m "Initial commit"

# 连接远程仓库
git remote add origin git@github.com:username/OR_ML.git

# 推送
git push -u origin main

六、验证安装 ​

创建一个测试脚本 test_install.py：

python
# test_install.py
import sys
print(f"Python version: {sys.version}")

import numpy as np
print(f"NumPy version: {np.__version__}")

import pandas as pd
print(f"Pandas version: {pd.__version__}")

import matplotlib
print(f"Matplotlib version: {matplotlib.__version__}")

import sklearn
print(f"scikit-learn version: {sklearn.__version__}")

import pulp
print(f"PuLP version: {pulp.__version__}")

print("\n✅ 所有库安装成功！")

运行测试：

bash
python test_install.py

七、常见问题 ​

Q1: pip 安装速度很慢 ​

使用国内镜像源：

bash
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple <package>

或配置永久镜像：

bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

Q2: Jupyter Notebook 无法打开 ​

检查端口是否被占用：

bash
# macOS/Linux
lsof -i :8888

# 如果被占用，使用其他端口
jupyter notebook --port 8889

Q3: VS Code 无法识别 Python 环境 ​

  1. 打开命令面板（Cmd + Shift + P）
  2. 输入 "Python: Select Interpreter"
  3. 选择虚拟环境中的 Python

八、准备好开始了吗？ ​

✅ 确认以下事项：

  • [ ] Python 3.10+ 已安装
  • [ ] Jupyter Notebook 可以正常启动
  • [ ] NumPy、Pandas、Matplotlib、scikit-learn、PuLP 已安装
  • [ ] VS Code 已安装并配置 Python 扩展
  • [ ] Git 已安装并配置用户名和邮箱
  • [ ] GitHub 账户已创建
